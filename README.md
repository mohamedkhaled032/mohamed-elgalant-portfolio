# MK.dev — Motion Edition (2026)

Responsive Flutter portfolio with a refined hero, code-editor motion, animated skills and project cards, section reveals, counters, and mobile navigation.

## Usage
- Open `index.html` in a browser (or use a static HTTP server).
- No dependencies or build step.
- Upload the contents of this directory to your existing GitHub Pages repository to replace the old site. No deployment has been performed automatically.
- All project descriptions, LinkedIn, WhatsApp, platform labels, and the approved CV are retained.
- `assets/mohamed-approved-portrait.png` is used exactly as supplied in the previous approved version, with no pixel modifications.
- Accessibility: focus styles, interactive cards and dialog, reduced-motion support.
